# CHANGELOG - Data Manager Full Improvements

## Version 2.0 - 2024-11-24

### 🎉 Major Features

#### 1. XLarge Preset - Production Scale
- **100 users** (tăng từ 50)
- **500 videos** (tăng từ 200)  
- **100 image slides** (giữ nguyên)
- **50 hashtags** (tăng từ 30)
- **10-30 comments per feed** (tăng từ 5-20)
- **5x interaction multiplier** (tăng từ 3x)
- **40% following rate** (tăng từ 30%)
- **5-20 search history per user** (mới)

#### 2. Real Metadata Tracking
- ✅ `views_count`: Counted from VIEW and WATCH_COMPLETE interactions
- ✅ `loves_count`: Counted from LIKE interactions  
- ✅ `shares_count`: Counted from SHARE interactions
- ✅ `comments_count`: Already existed, updated when creating comments

**Before:**
```javascript
{
  "loves_count": 0,
  "views_count": 0,
  "shares_count": 0,
  "comments_count": 0
}
```

**After:**
```javascript
{
  "loves_count": 45,    // Real count from LIKE interactions
  "views_count": 234,   // Real count from VIEW/WATCH_COMPLETE
  "shares_count": 12,   // Real count from SHARE interactions
  "comments_count": 18  // Real count from comments
}
```

#### 3. User Preferences Enhancement
- ✅ `watched_list`: Auto-populated from VIEW/WATCH_COMPLETE interactions
- ✅ `liked_list`: Auto-populated from LIKE interactions
- Both lists are automatically updated when creating interactions

**Before:**
```javascript
{
  "watched_list": ["random_id_1", "random_id_2"]  // Random
}
```

**After:**
```javascript
{
  "watched_list": ["feed_id_1", "feed_id_2"],  // From actual VIEW interactions
  "liked_list": ["feed_id_3", "feed_id_4"]     // From actual LIKE interactions
}
```

#### 4. Search History Collection
New collection to track user search queries:

```javascript
{
  "_id": "...",
  "user_detail_id": "...",
  "query": "dance",              // Hashtag, user name, or common query
  "created_at": "2024-11-20T..."
}
```

**Search Query Types:**
- Hashtag searches (from existing hashtags)
- User searches (from user display names)
- Common queries (funny videos, dance, music, etc.)
- Random queries (generated by Faker)

**Quantity per preset:**
- XLarge: 5-20 per user
- Large: 3-15 per user
- Small: 1-10 per user
- Test: 0-5 per user

#### 5. Increased Interactions
More interactions per feed item for richer data:

| Preset | Old | New |
|--------|-----|-----|
| XLarge | N/A | 15-50 interactions |
| Large | 3-15 | 9-30 interactions |
| Small | 2-10 | 6-20 interactions |
| Test | 1-5 | 3-10 interactions |

### 🔧 Technical Improvements

#### Code Changes

**1. Added search_history collection:**
```python
self.search_history_col = self.db['search_history']
```

**2. Enhanced _create_user_interactions:**
- Tracks views, likes, shares per feed item
- Updates metadata with real counts
- Updates user preferences with watched/liked lists
- Prevents duplicate counting (same user can only view/like once)

**3. Added _create_search_history method:**
- Generates realistic search queries
- Mixes hashtag, user, common, and random queries
- Timestamps distributed over last 30 days

**4. Updated PRESETS configuration:**
```python
PRESETS = {
    "xlarge": {...},  # NEW!
    "large": {...},
    "small": {...},
    "test": {...}
}
```

**5. Updated main menu:**
- Added option 1: XLarge dataset
- Renumbered existing options
- Updated input validation (1-6 instead of 1-5)

**6. Updated database operations:**
- `check_database()`: Added search_history
- `clear_all_data()`: Added search_history to cleanup
